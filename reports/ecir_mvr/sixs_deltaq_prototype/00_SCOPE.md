# SIXS-v2 Source-conditioned Delta-Q prototype scope

This is a development-only research branch. The frozen SIXS-v1 release and all
historical evidence remain unchanged. The experiment changes the primitive
belief target from absolute Reference geometry to signed
`Reference - Source` corrections and adds the corresponding current Source
primitive value to each prediction head.

The already-inspected AvgFlow final cohort is diagnostic-only and is excluded
from prototype tuning. Formal and large-holdout outcomes remain unread.
