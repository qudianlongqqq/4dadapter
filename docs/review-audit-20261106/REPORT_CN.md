# PINA 实证审计与修改结果

日期：2026-11-06。结论依据本轮实际执行的代码、冻结结果和新对照，不以先前的审稿预测代替实验。

## 核心判断

**方法有效的部分已有直接支持，但相对经典方法的优势尚未建立。** 同位移下，学习的解析动作优于去掉 Reliability、直接学习 Cartesian 方向和 TRAIN 统计表动作；同时，一个简单的 MMFF94s 梯度小步优于 Full。另发现了两项可以落实的改动：限制极端位移，以及明确区分原始 GEOM Reference 和扭转匹配后的 RDKit Reference。

这轮不应得出“方法无效”，也不应得出“论文原有机制全部证明”。应保留有证据的局部改进，修正比较协议和数据身份，再决定下一版方法设计。

## 1. 本轮实际做了什么

- 从冻结的 2,500 分子/5,000 Source 消融 cohort 中，按预先固定的分子身份 SHA256 排序选择 256 分子，保留每个分子的两条 Source，共 512 条。
- 预先指定三个 RMS 位移预算：0.00432154、0.01、0.02 Å；主比较预算为 0.01 Å，没有按结果选择最佳预算。
- 复用 Full、去 Reliability 重训模型、Cartesian 模型的三 seed 冻结坐标，重新归一化各自方向并使用相同预算。
- 新建 TRAIN 统计表 BA、统计表 bond-only、MMFF94s 全势梯度小步、受位置约束的 MMFF，以及只替换解析系数 σ 的对照。
- 使用冻结 GenBench3D 评估器与参考 KDE，实际评估 39,334 条构象；四项分量均保留，评估失败数为 0。
- 9 个原生方法/seed 在子集上共 4,608 个 V3D 判断，与历史保存结果完全一致；512 次 Full seed307 CPU 复现的坐标最大绝对误差为 4.135e-7 Å。
- 对原始完整 2,500 分子、三个 Full seed 共 15,000 条保存输出做了立体化学、位移尾部和分量转移普查。
- 新增限位移/立体化学保护变体，在同一子集实际评估 5,120 条构象；另对原始/标准化 Reference 配对评估 1,682 条构象，均无 evaluator failure。

这些是探索性重新分析。原 cohort 以前已被评估，本次不是全新的未触碰测试集。分子聚类 bootstrap 的区间描述固定模型下的分子抽样不确定性，不代表训练 seed 总体的不确定性。未新训练任何模型、未修改或覆盖投稿权重及正式结果。

## 2. 同位移比较：哪些贡献得到支持

固定每条 Source 的原始 Cartesian RMS 为 0.01 Å，再按冻结 SDF 的四位小数精度评估；序列化后的实际位移也保存。

| 方法 | V3D | Full 减该方法，百分点 | 95% 分子聚类区间 |
|---|---:|---:|---:|
| Source | 20.70% | — | — |
| Full，三 seed 平均 | 46.42% | — | — |
| 去 Reliability，三 seed | 34.51% | +11.91 | [9.05, 14.91] |
| Learned Cartesian，三 seed | 42.84% | +3.58 | [1.17, 6.12] |
| TRAIN 表 BA，无网络 | 33.20% | +13.22 | [8.92, 17.64] |
| TRAIN 表 bond-only，无网络 | 32.81% | +13.61 | [9.24, 18.10] |
| MMFF94s 梯度单步 | **53.52%** | **−7.10** | **[−11.26, −2.86]** |

统计表使用现有 TRAIN 校准中的类型上下文 median/scale，r=1，BA 家族等权或仅 bond。没有测试数据拟合、Reference 输入或网络。

**获得支持的结论：**在此数据与预算下，Full 的增益不只是移动更多；学习的 primitive 作用与解析方向有价值，也超过这里的非学习统计对照。Cartesian 对照仍保留 prediction 与控制器，因此这不是对所有 end-to-end 或 Flow-Matching 方法的结论。

**被限制的结论：**当前不能宣传相同微小干预下优于经典力场清理。MMFF 对照仅取 Source 点完整 MMFF94s 负梯度，投影/归一化后用相同位移；并没有进行长程优化或读取目标坐标。

受位置约束 MMFF 的三个预定强度也均报告：强度 100、1000、10000 的 V3D 分别为 60.35%、57.81%、28.91%，平均 RMS 分别为 0.03286、0.01134、0.00243 Å。它们不是精确同位移，但进一步说明应认真比较约束优化。每个设置最多 50 次迭代；未按结果选最优设置。

## 3. 贡献具有工作区间，不能外推为普遍方向优势

| RMS 预算 Å | Full | Cartesian | MMFF 梯度 |
|---|---:|---:|---:|
| 0.00432154 | 35.87% | 30.53% | 37.89% |
| 0.01 | 46.42% | 42.84% | 53.52% |
| 0.02 | 24.80% | 42.77% | 20.31% |

0.02 Å 时 Full 明显过冲，Cartesian 优势反转。不能把 0.01 Å 的优势解释成任意位移下解析方向更好。也不能简单把一次更新重复多次当作性能保证。

σ 系数独立干预：保持原有学习 μ、Reliability 和家族权重，只将解析系数中的 σ 换成 TRAIN 统计尺度，同时固定 0.01 Å 预算。seed307 的 V3D 从 46.88% 下降到 29.88%，差 16.99 pp，区间 [12.89,21.29]。这比原先同时改变 gate/τ 输入的消融更干净，但仍是冻结模型的推理敏感性实验；不能替代 fixed-σ 重训或证明其唯一必要性。

Source-conditioning 的必要性仍未得到证明。本轮没有新的 0000/0101 多 seed 训练，旧路由实验的解释维持不变。Equal BA 和 Bond-only 的既有近似位移筛选结果只支持小幅补充贡献，不应夸大。

## 4. 新发现：Reference 数据身份必须纠正

主消融 cohort 的 Reference 来自 `DRUGS/standardized_pickles`。上游 `standardize_confs.py` 先用 `EmbedMultipleConfs` 构造 RDKit 几何，匹配扭转角，再用新构象替换 `conf['rd_mol']`；可选 MMFF 的默认值为关闭。原始能量等 metadata 可能仍被保留，不能因此把坐标视作未经修改的 GEOM/xTB 坐标。尚未独立恢复该归档当年的完整生成命令，不能断言具体运行是否开启了可选 MMFF。

本轮核验了选中 256 分子的全部 6,355 个缓存 Reference：

- 所有缓存坐标与对应标准化归档完全相等；
- 所有构象的带原子索引拓扑一致，没有找到本地原子映射错配；
- 全部带有上游匹配 `rmsd` 标记；
- 此标准化池的 molecule-macro V3D 仅约 1.92%。**这不是原始 GEOM 的 V3D 上限。**

进一步选取这 256 分子中全部可按原始归档键恢复的 34 分子，将 841 个构象按 geom_id/原始 totalenergy metadata 配对，并逐个验证带索引拓扑：

| 同一批分子/构象的参考几何 | 分子平均 V3D |
|---|---:|
| 原始归档 GEOM 几何 | **55.27%** |
| 标准化后的几何 | **1.76%** |

配对差为 +53.50 pp，分子 bootstrap 95% CI [38.59,68.19]。这是参考身份对照，不是模型效果比较，也不是完整 GEOM 测试。

**影响范围：**本轮直接确认的是 primary-final 消融 cohort；不能据此断言 TRAIN 或其他所有 cohort 都错。源码显示 1,000 分子 breadth builder 读取的是 raw locator，与此不同。后续必须为各 cohort 分别写清原始/标准化 Reference；局部 MAE、构象内变化和 Source–Reference 距离的解释尤其需要修正。独立 V3D 的 Source→输出改善仍然是有效观察，但对物理参考几何的论断要绑定正确数据。

## 5. 完整保存输出的质量普查

完整 5,000 Source 的 V3D 是 22.26%；Full 三 seed 分别为 50.36%、50.02%、50.58%。逐 seed 的 V3D 修复数为 1510、1505、1525，原本通过却变失败的数量为 105、117、109。

键长通过率由 27.18% 升到约 61%；角度通过率由 76.06% 升到约 81%；芳香环平面分量不变。Clash 分量由 97.44% 轻微降到 97.38%，每个 seed 修复 2 条、损坏 5 条。提升主要来自 bond，同时存在逐样本损坏，不能写成所有样本或所有分量都改善。

每个 seed 的 5,000 条输出均检查到 2,428 个带标记四面体中心实例和 726 个指定 E/Z 键实例：**0 翻转、0 Source 退化、0 新增退化**。这是对保存数据的经验结果，不是理论保持保证；它只比较 Source 指定立体化学在坐标中的保持情况，不证明 Source 本身化学构型正确，也不覆盖所有类型的立体化学。

位移尾部则确实有问题。三个 seed 的最大单原子位移约为 0.902、0.582、0.306 Å；seed307 最大 RMS 达 0.221 Å。它们与历史 PER_RECORD/tau 保存值一致，不是本轮 SDF 对齐错误。平均 0.01 Å 左右不足以概括这类尾部。

## 6. 已实现并测试的修改

在独立分支 `audit/review-gaps-20261106` 中新增工具，未替换原模型默认行为：

1. **精确位移预算对照。** 各方向按每个构象自己的 RMS 归一化；零方向明确保持零。
2. **独立 σ 系数干预。** gate、学习特征、μ 保持原值，单独控制解析加权，避免原消融同时改变多个输入。
3. **可选的 bounded-stereo 输出包装。** 对 proposal 做统一缩放，限制 RMS 与最大单原子移动；检查 Source 指定的四面体与 E/Z 保持，必要时回溯或退回 Source；不使用 Reference、V3D 或能量作为接受 oracle。
4. **严格 Reference 校验。** 要求显式声明 `raw_geom` 或 `torsion_matched_rdkit`；拒绝将 `standardized_pickles` 标成 raw GEOM；逐构象检查带索引键拓扑与原子属性，弥补旧代码仅核对 atomic numbers 的不足。

在固定 512 Source 子集上的包装变体：

| 最大单原子位移限制 | 相比原生 Full 的 V3D 变化 | 说明 |
|---|---:|---|
| 0.10 Å | 0.00 pp | 三 seed 各触发 1/512 条；没有 V3D 通过状态变化 |
| 0.03 Å | −0.78 pp | 约 17–24% 样本触发；区间约 [−1.63,0.00] pp |

同时设置 RMS 上限 0.03 Å，并预留 0.0002 Å 序列化余量。检查了序列化后的限位与立体化学。本子集中 0.10 Å cap 的全局实际最大值小于 0.10 Å，但由于只触发少量记录，**不能宣称完整测试上已证明无损**。限位也不保证能量单调下降。

7 项针对性测试通过：预算、零动作、解析负梯度、σ 独立性、镜像翻转、E/Z、回溯/非有限输出，以及同元素错序与参考身份误标防护。`git diff --check` 通过。

## 7. 下一版应怎样推进

优先顺序建议：

1. **先修数据身份。** 审计 TRAIN、DEV、primary-final、主表、breadth 的 Reference 来源；在原始 GEOM 几何且与 TRAIN 分离的冻结 cohort 上复验相同对照。不要把标准化 pool 的离散度解释为真实量子构象的内禀变化。
2. **把 MMFF 当作必须超过的对照。** 当前方法尚未赢得同位移优势；考虑用 MMFF/BA 力作为先验，再学习残差或动作选择，但必须在开发集定方案后独立测试，不能从这些结果中挑一种混合系数当验证结果。
3. **保留有支持的部分。** Reliability 和学习尺度值得保留；是否必须 Source-conditioning，继续列为待验证。Direct Cartesian 的优势随预算反转，应报告完整曲线。
4. **保留尾部保护作为独立候选。** 0.10 Å 包装有实用潜力，下一步做完整 raw cohort、能量尾部与下游评估，再决定是否纳入正式默认推理。
5. 独立 Flow-Matching refiner、fixed-σ 多 seed 重训、路由多 seed、速度与下游效益仍未完成。本次没有自动启动昂贵训练，也没有将这些缺项标成通过。
